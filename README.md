# Intellect — site web

Page d'accueil statique (HTML/CSS/JS, sans build) : cours d'allemand A1–C1, préparation médecine en Allemagne, études et accompagnement en Russie/Allemagne. Langues : FR / EN / DE.

- Ouvrir `index.html` ou lancer `python3 -m http.server`.
- Photo du hero : déposer `assets/hero.jpg` (sinon une illustration s'affiche).
- Charte : bleu `#003865`, bleu clair `#2FB7F3`, orange `#FF8A00` (variables dans `css/style.css`).
- Le formulaire est une démo : à relier à un back-end, Formspree ou WhatsApp.
